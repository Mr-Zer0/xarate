# Supabase Configuration

This directory contains all Supabase backend setup files for the Personal Expense Tracker.

## Files

- **`SETUP.md`** - Complete step-by-step setup guide
- **`CHECKLIST.md`** - Interactive checklist to track setup progress
- **`migration.sql`** - Database schema and RLS policies
- **`storage-policies.sql`** - Storage bucket access policies

## Quick Start

1. Start with `SETUP.md` for detailed instructions
2. Use `CHECKLIST.md` to track your progress
3. Run the SQL files in your Supabase dashboard as instructed

## What Gets Created

- 4 database tables (households, users, categories, expenses)
- Row Level Security policies for multi-tenant data isolation
- Storage bucket for receipt images
- Authentication configuration
